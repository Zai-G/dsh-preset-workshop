# v0.4.0 · 2026-11-16

补齐三类能力：预设可打包分享、误改误删可找回、工具来源与身份可见。同时把会话中的 AGENTS 指令交回宿主官方加载器（预设只提供只读文件视图），源码语言由 JavaScript 迁移到 TypeScript，并适配 DSH `0.2.2-rc.2` / `0.2.2-rc.3`。本节覆盖 2026-11-11 以来的累计变更。

### 新功能

- **预设分享（导出）**：`portablePreset()`（`src/transfer/transfer.ts:57`）与 `writePresetArchive()`（`src/transfer/transfer.ts:80`）把多个预设打包为 ZIP，归档带固定标记 `ARCHIVE_MARKER = 'dsh-preset-workshop'`（`src/transfer/transfer.ts:10`）与 manifest `dsh-preset-workshop.json`；导出弹窗支持多选，默认全不选，格式选择为卡片式。ZIP 读写由 `fflate` 承担。
- **预设分享（导入）**：`readPresetArchive()`（`src/transfer/transfer.ts:87`）解析归档，`importPlan()`（`src/transfer/transfer.ts:121`）产出导入计划——可重命名、查看方案内容、逐项选择启用哪些工具与技能，一次窗口内完成。同名或相同 ID 冲突只提示重命名，不覆盖既有预设；导入一律新建、MCP 默认关闭、失败整批回滚。
- **分享保真**：便携预设只保存用户内容与来源摘要（每工具 ≤320 字符），不携带参数 schema；工具的自定义描述与使用提示随包导出并在导入后继续生效；环境快照、技能目录等动态内容在目标环境重新生成（相同段以 `inherit:true` 保存）。
- **分享脱敏**：`portableMcp()`（`src/transfer/transfer.ts:33`）把 MCP 的 env、HTTP 请求头与 URL 查询值替换为占位内容 `dsh-preset-workshop`，不回传连接密钥；导入后的连接保持关闭，补齐配置后可开启并检测。
- **预设快照**：`snapshotView()` / `viewSummary()`（`src/history/history.ts:44,64`）记录 System、User（含合并 AGENTS）、工具、MCP、技能与 token 估算；保存方案或恢复默认前自动留档；`snapshotDiff()` 与 `diffLines()`（`src/history/history.ts:67,85`）给出新增/移除与逐行差异，可切换为只看变化，同名工具的变化单独标出。
- **快照还原保护**：还原前先为当前状态（含未保存草稿）记录一份保护快照，还原之后仍可撤回；删除快照支持 5 秒撤销。
- **快照保留份数**：默认关闭，每预设保留 3 份，可调整为 1–9 份；降低上限按现有最大份数判断，不静默挤掉较新版本。
- **删除撤销**：自定义文本删除后 5 秒内可撤销，连续删除的多项可分别恢复；技能分组同样走 `groupOrderWithUndo()`（`src/history/history.ts:33`）。
- **技能分组**：分组全局共享，只用于筛选技能列表；预设实际启用的技能仍各自独立，分组的 `validateGroups()`（`src/history/history.ts:21`）在写入前校验。
- **官方工具来源标识**：工具描述窗口显示该工具来自哪个插件；同名工具给出说明帮助判断该启用哪一个，候选由 `catalog.withAlternates()` 生成，最多两个且 schema 相同即过滤。
- **官方工具图标**：为更多官方工具补充按用途的专属图标，同名工具使用统一通用图标。

### 变更与优化

- **源码语言与构建**：核心语言迁移到 TypeScript（`src/**/*.ts`）。`tsconfig.json` 输出到 `lib/`；`tsconfig.core.json` 对核心域（domain / history / storage / transfer）启用 `noImplicitAny` 做类型回归；`tsconfig.offline.json` 产出离线 mock。客户端与离线页分别由 `tools/build-client.mjs`、`tools/build-offline.mjs` 拼接为宿主要求的单模块。`npm run build` 从源码重建的 `lib/` 与仓库提交产物逐字节一致。
- **目录分层**：`src/{domain,storage,history,catalog,runtime,service,transfer,client}`；交付入口为 `lib/service/index.js`、`lib/runtime/scope.js`、`lib/client/client.js`，由 `package.json` 的 `exports` 与 `files` 白名单约束（npm 包只含 `lib`、`cordis.patch.yml`、`README.md`、`assets`）。
- **AGENTS 交回官方加载器**：预设不再自行构造 AGENTS 消息，改为通过 `instructionFileSystem()`（`src/service/sources.ts:105`）与对 `instructions` 服务的只读 `fs` 包装（`src/runtime/scope.ts:71-74`）向官方 `@deepseek-ai/dsh-agent-instructions` 提供当前预设的文件视图；基线、文件来源摘要、去重与增量更新全部由宿主负责。策略变化时移除尚未发送的正文，仅保留文件作用域提示，并以 `workshopPolicyRefresh` 标记触发宿主重读（`src/runtime/scope.ts:92-124`）；旧工坊私有基线只发送一次迁移说明（`source.kind = 'preset-workshop-instruction-migration'`，`src/runtime/scope.ts:158`）。
- **首屏**：先插入静态框架并禁用操作，snapshot 到达后启用；静态文案插入后立即本地化，修复英文界面短暂显示中文。
- **预览分层**：System 与 User（合并 AGENTS、环境、SKILL、时间与时区、自定义 User 块）分区呈现，长文本与版本对比按段渲染；环境块改用宿主实际的 `<system-reminder>` 外壳。
- **环境整合**：工作目录并入环境设置，与环境共用一个开关（`workshop:user-cwd` + `workshop:user-runtime`），时间与时区仍独立控制；关闭环境后，工作目录与 `harness:source`、`app:web-surface` 一并隐藏。
- **弹窗保护**：删除、还原等确认弹窗始终锁定；编辑类修改后需确认才关闭，减少误操作丢失。
- **继承内容**：编辑继承自官方的内容时直接显示当前正文，`inherit:true` 保留宿主原文、只管开关与顺序。
- **MCP 超时口径**：`MCP_CONNECT_TIMEOUTS = { stdio: 120000, 'streamable-http': 30000 }`（`src/runtime/scope.ts:13`），超时统一返回 `timeout`，与 `error` 区分。
- **依赖**：新增运行依赖 `fflate ^0.8.3`（低版本存在恶意压缩包解析风险，勿降级）；`js-yaml` 保持 `^4.1.0`。

### 修复

**AGENTS 与指令文件**

- 修复会话中 AGENTS 指令的标题与来源与官方不一致的问题：预设侧不再拼装提醒文本，一律由官方渲染器产出。
- 修复开关或指令文件变化后仍混入过期待发说明的问题：按当前策略重新计算内容。
- 修复全局指令文件与目录指令文件路径重合时被重复处理的问题：仍按全局开关处理。
- 修复单个全局根不可用（符号链接身份解析失败）导致其他根与目录候选一起失效的问题。

**工具与来源**

- 修复切换同名工具来源后两张卡片互换位置的问题：各自留在原有分组。
- 修复部分官方工具被归入第三方分组、个别工具名称显示不正确的问题。

**导入校验**

- 导入遇到同名预设或相同 ID 时提示重命名，不覆盖、不自动合并。
- 当前环境中不存在的工具不再允许勾选；遇到无法区分的同名工具来源时不擅自替用户选择。

**撤销与快照**

- 撤销删除不覆盖之后的修改；同名内容已重新创建时保留新内容。
- 修复快照数量与保存上限显示不准确的问题；降低上限时不再把已删除版本计入；切换预设后列表不再残留其他预设的条目。

**界面**

- 补齐部分按钮与说明缺失的英文文案；修复切换语言后部分文案不刷新、以及打开时短暂显示其他语言的问题。
- 空白的系统内容不再占据位置；关闭环境后工作目录等环境信息一并隐藏。
- 修复窄屏下文字重叠、页面被撑宽与说明被裁切的问题。

**分享安全**

- 升级 ZIP 解析组件（`fflate ^0.8.3`），消除一个已公开的安全隐患。
